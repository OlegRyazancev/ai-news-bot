# Daily Workflow

## Начало дня

```text
opencode
/start
/stage-status
```

## Новый этап

```text
/stage-start
→ проверить анализ, checklist и план
→ подтвердить реализацию
```

## Продолжение этапа

```text
/stage-status
→ выполнить следующую задачу текущего этапа
```

## Закрытие этапа

```text
выполнить раздел checklist «Что пользователь тестирует вручную»
→ сообщить агенту результат
→ этап остаётся открытым; сообщение результата не заменяет команду закрытия
/stage-close
```

Если при ручной проверке найдена ошибка, сначала выполняются исправление и повторная проверка; `/stage-close` вызывается только после успешного retest.

## Конец дня

```text
/handoff
git status
commit / push при необходимости
```

## Если потерял контекст

```text
/stage-status
```
