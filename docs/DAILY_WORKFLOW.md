# DAILY_WORKFLOW.md

## Ежедневный рабочий процесс (Vibe Coding)

```
opencode
/start
<задача обычным языком>
/handoff
```

## Типы сессий

| Сценарий | Команда |
|----------|---------|
| Новый день / чистая сессия / смена модели | `/start` (авто-читает весь контекст) |
| Продолжение прошлой сессии | `/start` (обновляет контекст) |
| Дать задачу | Просто опиши обычным языком |
| Крупная задача | "Это крупная задача — прочитай все доки, изучи код, покажи план сначала" |
| Проверить работу | "Запусти `npm run build` и `npm run lint`, исправь ошибки" |
| Закончить сессию | `/handoff` |

## Ответственность агента (Автоматически)

После каждой задачи агент **обязан**:
1. Запустить `npm run build` и `npm run lint`
2. Проверить `git diff`
3. Обновить `docs/CURRENT_STATE.md` и `docs/BACKLOG.md` если менялось
4. Дать резюме: что работает, что дальше

## Commit / Push

| Действие | Кто | Когда |
|--------|-----|------|
| `git add -A && git commit` | Agent | После **твоего явного подтверждения** |
| `git push` | Agent | Только по **твоему явному запросу** |

## Если агент ушёл не в ту сторону

1. **Стоп** — Не продолжай
2. **Покажи diff** — `git diff`
3. **Объясни** — Что изменилось и почему
4. **Предложи безопасный rollback** — Подтверди перед выполнением
