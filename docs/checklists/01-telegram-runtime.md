## Критерий завершения этапа

Этап **1. Telegram runtime** можно завершить только когда:

- бот запускается с реальным токеном и работает через long polling;
- базовые команды проверены через реальный Telegram API;
- `/start` сохраняет пользователя и начальные настройки в PostgreSQL;
- повторный `/start` не создаёт дубликаты;
- весь результат подтверждён runtime-проверкой.
