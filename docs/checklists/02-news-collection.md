# Stage 2 — Сбор новостей

Checklist этапа **2. Сбор новостей**. Канонические цель и критерий завершения находятся в [ROADMAP.md](../ROADMAP.md), фактическое состояние — в [CURRENT_STATE.md](../CURRENT_STATE.md), принятые решения — в [DECISIONS.md](../DECISIONS.md).

## Статус

✅ Завершено — реализация, проверки агента и ручная приёмка пользователем выполнены

## Цель

Автоматически получать новости об AI/LLM из выбранных доверенных RSS-источников, нормализовать их в единый формат и передавать результат в дальнейший поток обработки.

## Scope

### In scope

- Curated mix из 5–8 доступных официальных AI/LLM-фидов и независимых изданий.
- Получение RSS/Atom с ограничением времени запроса и изоляцией ошибок отдельных источников.
- Парсинг и нормализация обязательных и опциональных полей статьи.
- Встроенный регулярный запуск через `node-cron` в одном процессе приложения.
- Защита от одновременного запуска двух циклов сбора.
- Логи начала, результата и ошибок цикла без секретов и полного содержимого статей.
- Автоматические проверки нормализации и отказоустойчивости на контролируемых данных.
- Runtime-проверка реальных источников и автоматического запуска.

### Out of scope

- Сохранение статей в PostgreSQL, URL-based дедупликация и реальная команда `/latest` — этап 3.
- LLM-суммаризация, классификация и оценка важности — этап 4.
- Доставка дайджеста, breaking news и Telegram-уведомлений.
- Scraping HTML-страниц и платные новостные API.
- Распределённый scheduler, отдельный worker и поддержка нескольких экземпляров приложения.


2. Проверить startup-цикл по логам:

   - [x] Есть `News collection completed`: `sourceCount` и `successfulSourceCount` равны `8`, `failedSourceCount` равен `0`, необработанных ошибок и падения процесса нет.

### Проверка нормализованных статей

1. После остановки бота выполнить:

   ```powershell
   npm run build
   node -e "const { NewsCollector } = require('./dist/news/collector.js'); const { RssFeedReader } = require('./dist/news/feed-reader.js'); const { NEWS_SOURCES } = require('./dist/news/sources.js'); (async () => { const report = await new NewsCollector(NEWS_SOURCES, new RssFeedReader({ timeoutMs: 15000 }), { maxItemsPerSource: 3 }).collect(); console.table(report.sources.map(({ source, success, articleCount, error }) => ({ source: source.name, success, articleCount, error: error ?? '' }))); console.table(report.articles.slice(0, 10).map(({ title, url, source, publishedAt }) => ({ title, url, source, publishedAt: publishedAt.toISOString() }))); })().catch(error => { console.error(error); process.exitCode = 1; });"
   ```
