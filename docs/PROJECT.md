# PROJECT.md

## Цель продукта

**Персональный Telegram-бот для новостей об AI/LLM** — Сервис для одного пользователя, который автоматически собирает, дедуплицирует, суммаризирует и доставляет новости об AI через ежедневный дайджест и алерты о важных новостях.

## Основные функции (по приоритету)

1. **Авто-сбор** новостей об AI/LLM из доверенных источников
2. **Сохранение** статей с дедупликацией
3. **Оценка важности** каждой статьи
4. **LLM-суммаризация** статей
5. **Ежедневный утренний дайджест** (за последние 24ч)
6. **Breaking news** — доставка отдельно как только обнаружены (near-real-time, зависит от интервала опроса источников)
7. **Закреплённое сообщение-шпаргалка** — Популярные AI-модели по категориям (coding/reasoning/fast/cheap/free), обновляется на месте
8. **В будущем: Q&A** по накопленной истории новостей

## Основные ограничения

- **Single-user personal bot** — Бот для одного пользователя, не multi-tenant SaaS
- **Telegram-only** — Только Telegram, нет веб-интерфейса
- **Polling mode only** — Только polling-режим, webhook не реализован
- **PostgreSQL required** — Требуется PostgreSQL, нет SQLite
- **Node.js 20+** — Современные JS-фичи

## Что приложение ПОКА НЕ делает

- ❌ Сбор новостей из внешних источников (RSS, API, scraping)
- ❌ Дедупликацию статей
- ❌ Оценку/фильтрацию по важности
- ❌ LLM-суммаризацию
- ❌ Отправку запланированных дайджестов (нет шедулера)
- ❌ Breaking news алерты
- ❌ Закреплённое сообщение-шпаргалку
- ❌ Персистентность пользователя при `/start` (таблица User есть, но не используется)
- ❌ Персистентность подписок/предпочтений (схема есть, отложено)
- ❌ Тесты (vitest настроен, 0 тестов)
- ❌ Rate limiting, webhook, админ-интерфейс
